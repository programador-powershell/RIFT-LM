Formato de dados e compatibilidade

A página aceita o rift_phase1_gain_report.json e o rift_phase1_gain_history.csv gerados pelo script atual. Quando o teste ainda é apenas de uma operação Linear, a página não chama operações/s de Tok/s: Tok/s fica como “não medido”.

Para baterias completas de inferência, use campos como baseline_tok_s, rift_tok_s, baseline_ram_bytes, rift_ram_bytes, baseline_disk_bytes e rift_disk_bytes. O ganho é calculado automaticamente.
