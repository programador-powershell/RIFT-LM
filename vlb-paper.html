Abstract

VLB Native is an experimental model-conversion and inference stack designed to test whether an existing large language model can be re-quantized and executed through an independent runtime while preserving a frozen capability contract. The project separates storage compression, numerical kernel equivalence, complete model replay, capability retention and adaptive post-conversion learning.

A compressed artifact is never considered verified merely because tensor reconstruction metrics are high or because it occupies fewer bytes. The stack consists of strict streaming conversion, the VLB1 binary container, VLB-owned low-bit kernels, a VLB-owned HTTP inference server, a proof ladder for full-model retention, and teacher-free Autodidactic Mastery Training (AMT). The first target is google/gemma-4-E4B-it.

1. Research question

What is the smallest executable representation that can preserve every unit of a frozen capability contract under the target runtime?

Average perplexity, cosine similarity or aggregate accuracy can conceal local capability regressions. VLB therefore treats retention as a gate and efficiency as a property evaluated only after the gate.

The final inference path is intended to be independent from llama.cpp, bitnet.cpp, FreeToken, GGML/GGUF execution, PyTorch, Transformers, vLLM, ONNX Runtime or another LLM runtime. Reference frameworks remain allowed only on the reference side of validation.

3. Streaming conversion

The converter reads the Safetensors header and requests one tensor byte-range at a time. A real HTTP partial-content response is required. If the host ignores Range and attempts to return a full shard, conversion aborts before accepting the body as a valid tensor read.

Every converted tensor carries provenance: source file, byte range, shape, source dtype, target codec and artifact hashes.

4. VLB1

VLB1 is the native binary container for final VLB execution. Its purpose is to remove pickle and torch.save from the inference path. The model artifact records tensor layout, codec, dimensions, payload/scale offsets and model metadata required by the executor.

5. Initial profile: Q8_G64

The first proof profile uses symmetric group-wise 8-bit weights with group size 64:

s_g = max(abs(w_g)) / 127
q_g = clamp(round(w_g / s_g), -127, 127)
w_hat_g = q_g * s_g

Q8_G64 is not assumed lossless. It is a conservative first rung for developing the native stack before exploring lower-bit profiles.

6. Native kernel

The first VLB native operator is Q8_G64 matrix-vector multiplication, with scalar and AVX2/FMA CPU paths. Its proof must execute real matrices from the converted target artifact and record numerical disagreement such as maximum absolute error, RMSE, NRMSE and cosine.

Passing a kernel proof certifies the tested operator. It does not certify full-model intelligence retention.

7. VLB server

The VLB server must own the complete inference lifecycle: tokenizer, embeddings, normalization, attention, RoPE, feed-forward/expert layers, KV cache, low-bit matrix kernels, logits and decode. Missing native functionality must fail explicitly rather than fall back to another LLM engine.

8. KR100

Let a frozen validation contract contain N independent units. The candidate VLB runtime is evaluated on the same contract without using those units for training or calibration.

KR100 ⇔ passed_units == total_frozen_units

KR100 means 100% retention of the frozen certified contract. It is not a mathematical proof that every possible neural-network behavior is identical. Aggregate gains cannot compensate for a failed unit.

10. AMT

Autodidactic Mastery Training is teacher-free: no teacher logits, KL target or teacher hidden state. Its rule is minimum sufficient intervention. Validation distinguishes mastered capabilities from compute-limited behavior and likely learning gaps. Training runs in short targeted bursts followed by validation, with automatic commit or rollback.

The training-token budget is a ceiling, not an obligation.

11. Adaptive compute

The gate predicts marginal utility, not textual self-confidence: is another compute step expected to improve this state under the validation contract? Candidate features include latent state, latent delta, output entropy, top-1/top-2 margin and recurrence identity. Labels come from measured marginal gain.

12. Measurement contract

Primary results report only physically measured quantities: artifact bytes, peak RSS, accelerator memory where applicable, prefill/decode time, tok/s, per-unit quality metrics, generated tokens, kernel error and KR passed/total. If a quantity has not been measured, it remains absent/null rather than estimated into the primary result.

14. Falsification

A compression profile is rejected if the native artifact cannot satisfy the frozen retention contract, if retention requires effectively reverting to the canonical representation, if runtime-induced regressions remain after implementation bugs are excluded, or if the profile passes retention but provides no measured efficiency benefit.

15. First target and next milestone

The first full-model target is google/gemma-4-E4B-it. The next decisive milestone is a complete text forward/decode entirely inside vlb-server, followed by frozen full-model replay. Multimodal retention is a separate certification contract and will not be inferred from text-only success.
